# Homebrew Tap for PI-Desktop

Install PI-Desktop on macOS with Homebrew:

```sh
brew tap vastsa/pi-desktop
brew install --cask pi
```

Upgrade later with:

```sh
brew update
brew upgrade --cask pi
```

This tap publishes the official macOS ARM64 and Intel releases from [vastsa/PI-Desktop](https://github.com/vastsa/PI-Desktop). Release updates are synchronized automatically by GitHub Actions.
